序Claude Code って何？

Claude Code は「作業まで進める」AI

ふつうの AI チャットClaude Code
読めるもの会話に渡した文章や添付ファイル作業フォルダー内のファイルを、必要に応じて読む
できること答えを文章で返す許可された範囲で、ファイルを作る・直す、Web で調べる、手順を実行する
覚えていること基本はその会話の中だけCLAUDE.md などの申し送りを、会話の最初に読む

「答えを教えてもらう」ではなく、「フォルダーを渡して仕事を頼む」道具です。

ChatGPT などを使ったことがある人向けに、違いから入ります。一番の違いは、手元のファイルを必要に応じて読み、許可を得ながら書き換えられること。部下にフォルダーごと渡して頼むイメージです。デスクトップアプリや VS Code から使えます。
序Claude Code って何？

任せる仕事を支える 3 つの要素

文脈がないと「稼働報告を作って」と頼んでも、どの案件に何時間かわからない
ツールがないと予定表の中身を、毎回自分でコピーして貼ることになる
ガードレールがないと下書きのつもりが、メールを送ってしまうかもしれない
3 つそろって初めて安心して任せられます。文脈はパート 2「材料を集めて相談する」から、ガードレールは最後のパート 6「安心して任せるために」で詳しく扱います。ツールは最初はなくても始められるので、必要になったら足します。
序Claude Code って何？

モデル選択で、品質・速度・利用枠を調整する

モデルごとに、得意な作業と利用量の目安が異なります。API 利用は入出力トークン（AI が処理する量）で課金され、サブスクリプションはプランごとの利用枠で管理されます。

Opus（複雑な判断向け）

初めての作業や、慎重な検討が要る作業。

Sonnet（速度とのバランス型）

やり方が固まった繰り返し作業。

使えるモデルと利用枠は、プランや組織の設定で変わります。切り替えは画面のモデル選択（または /model）から。

日常業務を回す場面が増えると、資料を大量に読ませる頻度も上がります。慎重な検討が要る作業と、手順が固まった繰り返し作業でモデルを使い分けると、利用枠を計画的に使えます。API の料金とサブスクリプションの利用枠は別の仕組みです。/model は書籍外の補足です。

CLAUDE.md
## 基本方針
- 日本語で、明るいトーンで応対する（絵文字は少し）
- ユーザーは〇〇部で△△を担当している
- 技術用語には短い補足を添える

堅い仕様書ではなく、日々のお願いごとがただの箇条書きで並んでいるだけ。

書くのは AI。自分で書く必要も、文法を学ぶ必要もありません。

本の著者の CLAUDE.md の抜粋をもとに、個人情報を伏せて再構成しました。自己紹介や作業手順は Claude Code 自身に下書きを作らせられます。CLAUDE.md は行動を促すための申し送りであり、操作を確実に止める設定ではありません。

5文章の質と同時進行

文章を任せるときは「AI っぽさ」を消す

せっかくの成果物が「AI っぽい」の一言で軽く見られるのは、もったいない。

よくある癖

  • 太字と箇条書きだらけ
  • 整っているが、誰が書いても同じ
  • 体温のない文体

対処

避けたい癖をルールに書く。言葉にしきれない好みは、過去に自分で書いた資料や記事をサンプルとして渡す。

AI の文章が増えるほど、自分らしい語り口、現場の実感、正直な迷いの跡には価値が出ます。

実物を渡すのがいちばん効きます。人間らしさは AI の一般論では代わりがききません。
5文章の質と同時進行

複数の仕事を同時に進める

慣れてきたら、会話を複数開いて並行で任せられます。いちばん警戒すべきは、別の会話に指示を送ってしまうことです。

送る前に、どの仕事の会話かを確かめる。並行で資料を大量に読ませると利用上限にも届きやすくなるので、序で話したモデル切り替えと組み合わせます。

並行作業そのものより、指示の送り先を間違えるほうが事故になりやすい、という点を強調します。「送る前に確かめる」は一般的な対策として書いています。

ガードレールを支える 3 つの仕組み

権限設定

操作ごとに「許可」「確認」「拒否」を決めておく。送信につながる操作を拒否、など。

フック

特定の操作の前後に処理を差し込む。PreToolUse フックなら、条件に応じて操作を止められる。

権限モード

操作時の確認のしかたを選ぶ。自動モードは左の 2 つを整えてから。

書き方を覚える必要はない
メールやチャットへの送信操作は、必ず拒否される設定を入れて。入れたあと、本当に止まるか確かめて。
書籍外の補足です。本で「入出力をブロックする専用機能」とされているものの代表がフックです。設定ファイルの文法は覚えなくてよく、頼んで書かせ、効いているかを確認させるのが中級者向けの使い方です。

  • 整理せずに話しかけて、1 件やり切ってもらう
  • 「送信・申請はしないで」とガードレールを 1 行足す
  • 会議のあと、宿題を 1 つ投げてみる
  • うまくいった流れを手順書に残してもらう

集める、任せる、守る、育てる。この順で、使うほど仕事場が賢くなります。

全部を一度にやる必要はありません。1 件やり切って、それを手順書に残す。この 1 周を体験するのが最初のゴールです。
